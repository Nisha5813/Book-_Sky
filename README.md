# BookSky

BookSky is a simple book management website built using HTML, CSS, and JavaScript.

The project allows users to add book details and display them dynamically on the webpage.

## Features

- Add a book title, author name, and short description.
- Display added book details as book cards.
- Delete book entries from the webpage.
- Interactive popup form for adding book details.
- Background overlay when the popup form is displayed.

## Technologies Used

- HTML
- CSS
- JavaScript

## JavaScript Concepts Used

- DOM Manipulation
- Event Listeners
- Functions
- Dynamic Element Creation
- Template Literals
- Event Handling

## How It Works

1. Click the **ADD** button to open the book details form.
2. Enter the book title, author name, and a short description.
3. Click **Add** to display the book details on the webpage.
4. Click **Delete** to remove a book entry.

## Project Structure

- `index.html` - Structure of the webpage
- `sample.css` - Styling and user interface
- `book.js` - JavaScript functionality and DOM interactions
